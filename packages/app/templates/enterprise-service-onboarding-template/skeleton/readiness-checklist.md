# Readiness Checklist

## Catalog

- [ ] `catalog-info.yaml` ist vorhanden.
- [ ] Owner ist korrekt gesetzt.
- [ ] System-Zuordnung ist korrekt.
- [ ] Lifecycle ist korrekt gesetzt.

## Dokumentation

- [ ] TechDocs-Struktur ist vorhanden.
- [ ] Architektur ist beschrieben.
- [ ] Runbook ist vorhanden.

## CI/CD

- [ ] Pipeline-Datei ist vorhanden.
- [ ] Build-Schritt ist definiert.
- [ ] Security Scan wird ergänzt.
- [ ] Deployment-Schritt wird ergänzt.

## Kubernetes

- [ ] Deployment manifest ist vorhanden.
- [ ] Service manifest ist vorhanden.
- [ ] Ingress manifest ist vorhanden.
- [ ] Namespace ist korrekt.
- [ ] Resource Limits werden ergänzt.

## Security

- [ ] CODEOWNERS ist gesetzt.
- [ ] SECURITY.md ist vorhanden.
- [ ] Keine Secrets im Repository.
- [ ] Data Classification geprüft.
